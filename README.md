# Banco de Dados Relacional – Fundamentos, Modelagem e Normalização

Projeto completo desenvolvido para demonstrar domínio em:
- fundamentos de bancos de dados,
- modelagem conceitual (MER/DER),
- modelo relacional,
- normalização (1FN, 2FN, 3FN),
- implementação em SQL.

Inclui estudos de caso reais e scripts SQL prontos para execução.
