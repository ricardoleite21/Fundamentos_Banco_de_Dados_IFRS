# Banco de Dados – Fundamentos, Modelagem e Normalização

Projeto acadêmico e técnico desenvolvido com foco em **fundamentos de bancos de dados relacionais**, **modelagem conceitual**, **modelo relacional** e **normalização de dados**, estruturado para demonstrar domínio teórico e aplicação prática dos principais conceitos exigidos pelo mercado.

Este repositório foi construído com **organização profissional**, **documentação clara** e **exemplos reais**, sendo adequado para avaliação técnica em processos seletivos.

---

## 🎯 Objetivo do Projeto

Demonstrar capacidade de:

- Compreender e aplicar **fundamentos de bancos de dados**
- Realizar **modelagem conceitual (MER/DER)**
- Converter modelos conceituais para o **Modelo Relacional**
- Aplicar **normalização até a 3ª Forma Normal**
- Implementar estruturas de dados em **SQL**
- Resolver **problemas reais de modelagem**, evitando redundância e anomalias

---

## 🧠 Conteúdos Abordados

### 🔹 Módulo 1 – Conceitos Fundamentais
- Banco de Dados e SGBD  
- Hierarquia dos dados  
- Arquitetura ANSI/SPARC  
- Independência de dados  

### 🔹 Módulo 2 – Modelagem de Dados
- Modelos de dados (Hierárquico, Rede, Relacional)  
- Modelo Entidade-Relacionamento (MER)  
- Entidades, atributos, relacionamentos  
- Cardinalidade, grau e restrições  
- Diagrama Entidade-Relacionamento (DER)  

### 🔹 Módulo 3 – Modelo Relacional
- Relações (tabelas), tuplas e atributos  
- Domínios  
- Chaves primárias, estrangeiras e compostas  
- Integridade referencial  
- Mapeamento MER → Modelo Relacional  

### 🔹 Módulo 4 – Normalização de Dados
- Dependência funcional  
- Anomalias de inclusão, exclusão e atualização  
- 1ª, 2ª e 3ª Formas Normais  
- Normalização baseada em documentos reais  

---

## 🧪 Estudos de Caso Reais

### 📄 Normalização de Nota Fiscal
- Identificação de atributos multivalorados  
- Separação de entidades (Nota, Cliente, Produto, Itens)  
- Eliminação de redundâncias  
- Modelagem final em 3FN  

### 📄 Normalização de Formulário de Remanejamento
- Campos repetitivos e dependências transitivas  
- Criação de tabelas associativas  
- Separação de entidades funcionais  
- Modelo final altamente normalizado
